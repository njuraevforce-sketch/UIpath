NFTALT is a personal diary. No account or sign-in is required.

Review flow:
1. On Home, tap Write. Add a title and text, select a mood and cover, and tap Done.
2. Close and reopen the app to verify that the entry is saved.
3. Use Calendar to find the entry by date.
4. In Entries, search for text and mark the entry as a favorite.
5. In Profile, change the profile name or illustrated avatar.
6. Export entries opens the iOS share sheet with a JSON backup. Import entries opens the native Files picker. Backups are processed locally.
7. Profile > Settings includes larger text, Refresh from server, and confirmed deletion of local diary data.
8. Profile > Privacy explains local storage and links to the privacy policy.

The diary interface loads from https://nftalt1.com/ when online. If loading fails, the app uses a bundled copy of the diary. Saved entries are mirrored in the native application container and remain available in either mode. Refresh is initiated from Settings or on a new launch, so it does not interrupt writing. A privacy cover hides the diary when the app is inactive.

Diary entries and the optional profile name are not uploaded. Technical hosting logs retain request information for server operation/security; this is declared as Other Diagnostic Data for App Functionality, linked and not used for tracking.
