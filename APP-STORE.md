# App Store preparation

See `app-store/RELEASE-CHECKLIST.md` for the current release status, `app-store/metadata.en.json` for English listing text, and `app-store/REVIEW-NOTES.en.txt` for reviewer instructions.

The primary app is a Vue 2 PWA. App Store distribution requires a signed iOS wrapper. Both HBuilderX and standalone Xcode source projects are included; choose one, validate its final binary and complete on-device testing before submission. No signed IPA or Apple approval is included.
